## Authoring rules applied

- Follows the approved 90-day Machine Learning Engineer syllabus order for Days 1–10.
- Separate class notes and interview questions for every day.
- Beginner-first explanations, then practical and interview-level context.
- Code examples include expected outputs and explanations.
- Scenario-based questions include answers and follow-up questions.
- No daily projects, MCQ quizzes, AI mentor prompts or unrelated mentoring content.
- Formulas use plain text and standard Markdown; no LaTeX.
- Images are referenced only when they materially improve understanding; these first ten topics are explained with text diagrams and tables, so no extra image assets are required.
